EUAN RUSSELL WEBSITE — QUICK EDITING GUIDE

PREVIEW THE WEBSITE
- Keep all five files in the same folder.
- Double-click index.html to open the website in your browser.

CHANGE YOUR CONTACT EMAIL
- Open index.html in Notepad.
- Press Ctrl+F and search for YOUR_EMAIL@example.com.
- Replace it with your email address and press Ctrl+S.

EDIT OR ADD PORTFOLIO PROJECTS
- Open projects.js in Notepad.
- Edit the example project title, label, description, video and image.
- Categories must be exactly: cinematic, social, sport, travel or commercial.
- To add another project, copy one complete project object (from its opening { to its closing }), paste it before the final ]; and add a comma between objects.
- Paste a YouTube or Vimeo URL into video. The project thumbnail will link to that video.
- Paste a direct image URL into image for a thumbnail. Leave it blank if you do not have one yet.
- Save with Ctrl+S, then refresh the browser preview.

PUBLISH OR UPDATE ON NETLIFY
- First publish: extract this ZIP and upload the extracted euan_russell_simple_site folder to Netlify Drop.
- Later updates: upload the updated folder through your site's Netlify Deploys page.
- Do not upload just index.html. Upload the complete folder with all five files.

This starter website uses external video links rather than hosting large video files itself.
